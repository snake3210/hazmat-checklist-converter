## 🛠️ 本地端使用方式

若需要離線在本機使用，本專案提供兩種雙軌操作工具：

### 1. 桌面 Web 介面
- 雙擊執行 `開啟前端網頁介面.bat` 或直接用瀏覽器開啟 `index.html`。
- 支援檔案拖曳、整批資料夾載入、即時處理進度顯示與一鍵打包 ZIP 下載。

### 2. Python 批次轉換工具
- **一鍵批次處理**：雙擊 `一鍵批次轉換全部.bat`，自動轉換預設目錄下所有檢查表。
- **拖曳檔案即轉**：直接將任何 `.docx` 檔案或資料夾拖曳到 `拖曳檔案到這裡轉換.bat` 上方放開。
